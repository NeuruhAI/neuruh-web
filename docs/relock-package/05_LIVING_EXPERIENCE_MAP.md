# Neuruh.com Living Experience Map

## Global rule

The visitor may experience a cinematic journey, but every chapter has an inspectable
truth layer and every essential statement exists in semantic DOM.

## Chapter 0 — Presence

### Visible
The N-Cell is present and materially alive.

### Truth
Display:

- current public snapshot mode;
- last verified timestamp;
- number of public worlds;
- current live/staging/blocked/planned distribution;
- explicit limitation when the feed is a snapshot.

### Interaction
Approach, inspect, or skip directly to the architecture.

## Chapter 1 — Fragmentation / The Estate

### Source model
Local AI Estate and Archive Refinery.

### Experience
Fragments are not random debris. They are typed assets:

- repositories;
- prototypes;
- engines;
- connectors;
- documents;
- receipts;
- agents;
- datasets;
- deployments;
- product families.

Each fragment has custody, provenance, maturity, sensitivity, and canonical status.

### Living behavior
Use current public-safe registry counts when available. Otherwise show a dated verified
snapshot. Never present remembered counts as current truth.

## Chapter 6 — World Emitter

Each product becomes a world with a distinct visual and operational identity.

### DeedSonar

### Find Sell Profit

## Chapter 7 — Governed Execution

### Public-safe demonstration

signal → evidence → contradiction → scenario → authority gate →
approved sandbox action → receipt → state update.

The user can open every hop.

No external write occurs.
