# Neuruh.com Canonical Product Ruling

## Product category

Neuruh.com is the public operating projection of a modulated agentic organization.

It must explain and demonstrate that independent products, platforms, memory systems,
evidence systems, governance, and execution can act as one organism without becoming one
monolithic application.

## The central truth

The breakthrough is not a graph, a model, or a 3D object. It is the architecture that
allows the products to become one system without erasing their independence.

## The public experience must continuously answer

1. What exists?
2. What state is it in?
3. What does it depend on?
4. What evidence supports that state?
5. Who or what owns the next decision?
6. What should happen next?
7. What changed over time?
8. What is live, verified, simulated, conceptual, blocked, or unknown?

## Definition of "alive"

A surface is alive only when at least one of these is true:

- it reacts to a real signed system event;
- it renders a verified timestamped snapshot;
- it exposes a real evidence or decision chain;
- it allows a user to traverse actual system relationships;
- it changes based on a governed state machine;
- it truthfully declares that it is a sandbox or conceptual demonstration.

Ambient motion alone does not qualify as life.

## Public operating boundary

Neuruh.com is read-only.

It may expose public-safe:

- product and organ state;
- maturity;
- dependencies;
- evidence coverage;
- selected receipts;
- release history;
- public research;
- public artifacts;
- governed sandbox demonstrations.

It must not expose:

- private local paths;
- secrets;
- customer data;
- sensitive defense details;
- private archive contents;
- unreviewed personal memory;
- internal credentials;
- unapproved future claims.

## Direction A reinterpretation

The Biological-Architectural world is not visual biology pasted onto software.

Every visual structure must map to a real role:

- outer membrane = governance and public/private boundary;
- internal membrane = evidence threshold and review boundary;
- core = context compilation and inference authority;
- channels = data, control, evidence, and receipt pathways;
- cells/worlds = independent products and organs;
- branching = scenario generation and optionality;
- tension = contradiction or productive polarity;
- illumination = verified evidence, not generic activity;
- scar/occlusion = blocked, degraded, quarantined, or contradicted state;
- contraction = gate or authority refusal;
- emission = approved action;
- return wave = receipt and outcome;
- structural change = governed learning or architecture update.

## Non-negotiable claim discipline

Every public object and number must be classified:

- LIVE
- VERIFIED_SNAPSHOT
- SANDBOX
- CONCEPTUAL
- PLANNED
- BLOCKED
- UNKNOWN

No seeded data may present as live.
No motion may imply a successful execution that did not occur.
No product may appear healthy because the visual direction needs more green.
