# Claim Discipline Matrix

| Subject | Allowed public claim | Truth/claim class | Prohibited promotion |
|---|---|---|---|
| Neuruh Alive | Public-safe dated self-model exists | VERIFIED_SNAPSHOT / ARCHITECTURE | Live operating feed or autonomous organization |
| Local AI Estate | Fragmentation/custody architecture and observed evidence exist | VERIFIED_SNAPSHOT / ARCHITECTURE | Current private counts, paths, or ship-ready inventory |
| Galaxy | Interface and operating model are observed | VERIFIED_SNAPSHOT / OBSERVED | Current production connectivity or sourced health percentages |
| Neural Core | Compound memory/retrieval/tool architecture is specified | VERIFIED_SNAPSHOT / ARCHITECTURE | Deployed personal model or completed training system |
| Adaptive Intelligence | Claim lifecycle and visual requirements are specified | VERIFIED_SNAPSHOT / ARCHITECTURE | Guaranteed emergence or live continual learning |
| LCDE / Case Zero | Falsifiable hypothesis and blinded protocol exist | CONCEPTUAL / HYPOTHESIS | Empirical proof, clinical guidance, or universal law |
| DeedSonar | Multiple property-intelligence surfaces are observed | VERIFIED_SNAPSHOT / OBSERVED | Canonical live backend or current acquisition activity |
| Find Sell Profit | Category, doctrine, and market architecture are founder-confirmed | VERIFIED_SNAPSHOT / THREAD_CONFIRMED | Proven scoring, transactions, customers, or revenue |
| DATUM | Valuation engine/surface architecture is documented | VERIFIED_SNAPSHOT / ARCHITECTURE | Live public valuation service or financial advice |
| Factory / Visual Cortex | Local surfaces support the concept | VERIFIED_SNAPSHOT / OBSERVED | Active public production engines or publishing authority |
| Founder | Years of fragmentation, rebuilding, persistence, and coherence thesis | VERIFIED_SNAPSHOT / THREAD_CONFIRMED | Invented critics, counts, hours, investment, or completion |
| P0 foundation | Recorded local technical checks passed | VERIFIED_SNAPSHOT / OBSERVED | G1 device validation or G2 renderer certification |

Truth mode is not maturity. Maturity is not evidence status. A visual `STABLE` state does not
create a `LIVE` claim. Metrics require value, classification, unit, as-of timestamp, and source.
